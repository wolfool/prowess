# Prowess — 능력치 · 강화 · 장신구 · 무기 스킬

바닐라 방어의 상한(방어구 20점에서 감소 80%로 잘림)을 버리고 **피해 계산을 다시 하는**
마인크래프트 RPG 플러그인.

- **Minecraft** 1.21.4
- **서버** Paper (또는 Paper 계열 포크)
- **Java** 21

> 이 저장소의 소스는 2026-08-11 자 `Prowess-1.0.0.jar` 를 역컴파일해 복구한 것입니다.
> 원본 주석은 남아 있지 않습니다. 복구하며 장신구 저장이 snakeyaml **내부 클래스**
> (`org.yaml.snakeyaml.external.biz.base64Coder.Base64Coder`)에 기대던 것을 표준
> `java.util.Base64` 로 바꿨습니다 — 서버가 쓰는 라이브러리 판이 달라져도 안전합니다(1.0.1).
> 옛 저장 데이터(MIME 줄바꿈)도 `MimeDecoder` 가 그대로 읽습니다.

---

## 핵심

### 바닐라 방어를 버린 피해 계산

감소율은 `방어 / (방어 + defense-k)` — **상한이 없고 100%에 닿지 않습니다.** 실질 체력이
방어에 비례하기 때문에 "방어 100 더"의 값어치가 어디서나 같습니다. 바닐라 방어구 점수와
맷집은 방어로 환산하므로(네더라이트 한 벌 = 방어 80 출발) 바닐라 장비도 그대로 쓸 수 있습니다.

- 몹은 바닐라 방어구 점수로 환산한 방어를 갖습니다.
- PvP 는 배수로 눌러 둡니다 (`pvp-factor`). 강화 차이가 한 방이 되면 늦게 온 사람이 할 게 없어집니다.
- 허수아비(`Target_Dummy`)는 죽지 않고 맞은 피해만 액션바에 쌓입니다.

### 강화 — `/강화`

최대 15단계. 단계마다 원래 능력치의 비율만큼 얹습니다(곱이 아니라 덧셈). 3단계까지는
실패해도 안전하고, **장비가 부서지지는 않습니다.** 단계별 확률·비용·재료는 `gear.yml`.

### 장신구 — `/장신구`

반지 두 칸 · 목걸이 · 귀걸이. 아이템은 **플레이어에게** 새겨지고, 나눠 준 장비의 강화
단계는 **아이템에** 새겨져 그대로 따라갑니다.

### 무기 스킬

무기 하나에 네 칸. 강화가 오르면 하나씩 열립니다(+0 / +4 / +8 / +12).

| 조작 | 쓰는 것 |
|---|---|
| 우클릭 | 첫 번째 |
| 웅크리기+우클릭 | 두 번째 |
| 좌클릭 (허공) | 세 번째 |
| 웅크리기+좌클릭 | 마지막 |

갈래는 참격 · 회전베기 · 돌진 · 도약 · 각성 · 꿰뚫기 · 빙결 · 운석 · 연쇄 · 소용돌이 ·
균열 · 처형 · 수호 · 띄우기 · 연사 등. 무기와 갈래의 연결은 `skills.yml` 의 무기 아이디
(CraftEngine 아이디)로 정합니다.

### 파티 — `/파티`

서로 때리지 않게 하고, 화면 오른쪽에 서로를 띄웁니다. **저장하지 않습니다** — 서버를 껐다
켜면 흩어집니다(몇 달 전 파티가 남아 먼저 나가기부터 해야 하는 일을 막기 위해).

### 밖으로 내보내는 것

- **PlaceholderAPI** 확장으로 능력치를 다른 플러그인에서 읽습니다.
- `ProwessApi` 로 다른 플러그인이 능력치를 읽고 장비에 새길 수 있습니다.
- **Vault**(강화 비용) · **Mastery**(직업 특전) · **CraftEngine**(아이템 아이디) ·
  **Epithet**(칭호 특전) 과 연동하며, 없어도 해당 몫만 빠지고 그대로 돕니다.

## 명령어

| 명령 | 하는 일 |
|---|---|
| `/prowess 진단·스킬·새기기·리로드` | 관리 (권한 `prowess.admin`) |
| `/스탯` | 지금 내 능력치 |
| `/강화` | 장비 강화 창 |
| `/장신구` | 반지·목걸이·귀걸이 창 |
| `/파티 초대·수락·거절·나가기·추방` | 파티 |

## 설정

`config.yml`(피해 공식·직업·칭호·파티) · `gear.yml`(장비 능력치·강화 단계) ·
`skills.yml`(무기 스킬). 고친 뒤 `/prowess 리로드`.

## 빌드

```
./gradlew build          # build/libs/Prowess-1.0.1.jar
```

또는 Gradle 없이 바로: `build.ps1` — JDK 21과, 한 단계 위 `libs\` 폴더에
paper-api · adventure · Vault · PlaceholderAPI jar 가 있으면 됩니다.
